# ねだん帳 Ver 1.0

スーパーで買う食品の価格を記録して、店頭で「安い・普通・高い」を判定する自分専用の相場帳アプリ。

## 特徴

- **完全オフライン動作**: データはすべて端末のブラウザ内(localStorage)に保存。スーパー店内で電波が弱くても瞬時に動く
- **月額0円**: サーバー不要の静的 PWA
- **3秒で判定**: 品目を検索 → 価格を入力 → 「安い／普通／高い」が即表示

## 使い方

### スマホでの初回セットアップ

1. Chrome でアプリの URL を開く
2. メニュー(︙)→「ホーム画面に追加」(または「アプリをインストール」)
3. ホーム画面の「ねだん帳」アイコンから起動 → 以後は圏外でも使える

### 店頭での使い方(3秒チェック)

1. 「しらべる」タブで品目を検索(例: 鶏むね)
2. 品目をタップ → 店頭の価格を入力
   - **肉・魚などの100g管理の品目**: パックの値段と内容量(g)を入力 → 100gあたりの単価を自動計算
   - **卵・牛乳などの単品管理の品目**: 値段をそのまま入力
3. **安い／普通／高い** が即表示 → そのまま「この価格で登録する」で記録

100g管理にするかどうかは品目ごとに設定できます(設定タブ → 品目の編集 → 「100gあたりの単価で記録する」)。

### 判定のルール

- 直近30日の平均価格と比較
  - 平均より **10%以上安い** → 「安い」
  - **±10%以内** → 「普通」
  - **10%以上高い** → 「高い」
- 直近30日の記録が3件未満の品目は「判定なし」
- 登録した価格が過去365日の最安値を下回ると「🎉 最安値更新！」

### スマホ・PC間の同期

Google ドライブ経由でスマホとPCのデータを自動で合体できます。初期設定(1回・約5分)は [SYNC_SETUP.md](SYNC_SETUP.md) を参照。設定しなくてもアプリは各端末で独立して使えます。

### バックアップ

**設定タブ → エクスポート** で JSON ファイルを保存できます。機種変更やデータ消失時は **インポート** で復元できます。同期を設定している場合は Google ドライブの `nedancho-data.json` も実質バックアップになります。

## 開発メモ

- 構成: HTML + バニラ JavaScript + CSS(外部ライブラリなし)
- PWA: `manifest.webmanifest` + `sw.js`(キャッシュファースト)
- **ファイルを更新したら `sw.js` の `CACHE_VERSION` を上げること**(上げないとスマホ側が古いキャッシュを使い続ける)
